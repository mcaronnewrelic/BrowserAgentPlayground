UserAction All three signals land as the same event type with a boolean flag: rageClick, deadClick, errorClick. It's automatic: user_actions.enabled defaults to true on the Pro and Pro+SPA agent, so no snippet change was needed for this page. 
// Rage click: 4+ clicks, same element, under 1s
button.click() // x4, fast
// -> rageClick: true

// Dead click: a button/link click, then 2s of nothing
function onSubmit() { /* ...nothing visible happens... */ }
// -> deadClick: true

// Error click: a click, then an error inside that 2s
newrelic.noticeError(err)
// -> errorClick: true

Everyone shares one New Relic account, so your clicks are tagged as demoUser and demoCode custom attributes (your name is also set as your end-user ID via setUserId()), carried onto every UserAction event you generate below.

How the agent decides

Three ways a click says something's wrong

This runs automatically. Nothing on this page tells the agent what counts. It's on by default on the Pro and Pro+SPA browser agent (init.user_actions.enabled), watching every click on every page.

Rage click: the same element gets 4 or more clicks, and the first and the fourth land under a second apart.

Dead click: a click on a button or link, then 2 seconds in which nothing on the page changes: no DOM update, no request, no navigation.

Error click: a click on a button or link, then a JavaScript error inside that same 2-second window, thrown or reported with noticeError().
