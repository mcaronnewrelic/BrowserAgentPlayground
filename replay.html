How replay actually behaves

Masked by default, recorded by luck, unless you force it

Masked by default: every bit of text and every input on this site renders as asterisks in a replay unless explicitly unmasked. This isn't a quirk of this demo, it's New Relic's own recommended default setting. Every replay recorded on this site before this page existed is a wall of asterisks.

recordReplay() / pauseReplay(): this app only samples 10% of sessions into full recording (sampling_rate: 10). recordReplay() forces this session into full recording regardless of that roll, agent v1.240.0+, which is the only reliable way to guarantee this demo produces something to look at.

The lead-up problem: this snippet also has preload: false, so a session waiting on an error (error_sampling_rate: 100) isn't buffering anything beforehand. If an error happens, the replay only starts recording from that moment forward, it can't rewind. Calling recordReplay() up front is the only way to capture what led up to whatever you're about to click.

nr-unmask / nr-block / nr-ignore: three ways to override the default. nr-unmask makes specific text readable again. nr-block excludes an element and its children entirely, an empty box in the replay, not just masked text. nr-ignore keeps an input field visible but never records what you type into it.
