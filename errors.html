JavaScriptError Errors and logs are different event types. Uncaught errors and noticeError() create JavaScriptError events. console.error creates an ERROR Log. This page shows both. 
// 1. Uncaught errors are captured automatically
cart.total.toFixed(2) // TypeError

// 2. Report errors you catch and handle
try { applyCoupon(code) }
catch (err) {
  newrelic.noticeError(err, { coupon: code })
}

// 3. Drop the noise, group what matters
newrelic.setErrorHandler(err =>
  /ResizeObserver/.test(err.message)
    ? true : { group: 'Checkout' })

Everyone shares one New Relic account, so we tag your errors. Your name and code are attached as demoUser and demoCode. The error messages stay the same for everyone, so identical errors group together. Your name is also set as your end-user ID via newrelic.setUserId(), which is what powers the Users affected count in Errors Inbox.

Method 1 · Automatic

Uncaught errors and promise rejections

No code needed. The agent listens for anything your app fails to catch. Each button causes a genuine error of that type, so the error class and stack trace are real.

Method 2 · Handled errors

newrelic.noticeError()

Your code caught the error and recovered, but you still want to know. The user sees nothing.


            

              
            

          


          
          

            
Method 3 · Filter and group

            
newrelic.setErrorHandler()

            
One handler sees every error before it is sent. Return true to drop it, or { group } to label it in Errors Inbox. Edit the rules, then throw an error that matches.

            

              

                
                

                  

                

              

              

                
                

                  

                  

                

              

            

            

          


          
          

            
Errors vs. error logs

            
One failure, two signals

            
An error tells you what broke with a stack trace, grouped in Errors Inbox. An ERROR log tells you what was happening in your own words. Send both, linked by a shared errorId, and you can jump from one to the other. Compare it with the Logs demo.
