Core Web Vitals time the page. Marks and measures time what only you know matters: a search, a checkout step, a widget becoming usable. The agent turns each one into a BrowserPerformance event.

Start timing → Jump to the query
Off by default The agent ignores performance.mark() and performance.measure() until you turn on init.performance.capture_marks and capture_measures. This site turns both on in nr-init.js. newrelic.measure() works with or without them. 
// A mark is a point in time (duration 0)
performance.mark('search:start')
// ...the work you care about...
performance.mark('search:end')

// A measure is the time between two points
performance.measure('search', 'search:start', 'search:end')
// -> BrowserPerformance, entryType 'mark' / 'measure'

// Or skip the marks and ask the agent directly
newrelic.measure('checkout', { start: t0 })
// -> BrowserPerformance, entryType 'measure'

Everyone shares one New Relic account, so your clicks are tagged as demoUser and demoCode custom attributes (your name is also set as your end-user ID via setUserId()). The agent copies them onto every BrowserPerformance event you create below.

What becomes what

Three calls, one event type

performance.mark()A browser API, not New Relic's. Becomes a BrowserPerformance event with entryType mark and an entryDuration of 0. Anything in detail becomes entryDetail.* attributes.
performance.measure()Also a browser API. The time between two marks (or a start and an end you give it). Becomes entryType measure, with its length in entryDuration (milliseconds).
newrelic.measure()The agent's own call. Also lands as a measure, but makes no entry in the browser's timeline. Its customAttributes become top-level attributes, not entryDetail.*.
1 · Mark a moment

performance.mark()

Records the instant you click. Useful as a "this happened here" pin, and as the start or end of a measure.

performance.mark('demo:button-clicked', {
  detail: { button: 'mark', clicks: 1 }
})

No mark yet.

2 · Measure between marks

performance.measure()

Marks the start, loads data/products.json, waits as long as you pick, marks the end, then measures between the two marks. One click, three events.

No search yet.

3 · Ask the agent directly

newrelic.measure()

Saves the start time with performance.now(), runs a fake checkout, then hands the start to the agent. No marks needed. The end defaults to now.

const t0 = performance.now()
// ...checkout runs...
newrelic.measure('demo:checkout', {
  start: t0,
  customAttributes: { step: 'payment', cartItems: 3 }
})

No checkout yet.

4 · Since the page loaded

newrelic.measure(name)

With no options, start defaults to 0, the moment this page started loading, and end to now. A quick way to time "how long until people do X".

newrelic.measure('demo:time-to-click')
// returns { start: 0, end, duration, customAttributes }
