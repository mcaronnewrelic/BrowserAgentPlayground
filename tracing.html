Logs in the trace

Put your logs on the same trace

The agent puts trace headers on your requests automatically, but it does not add a trace ID to browser logs from newrelic.log() or wrapLogger(). Add it yourself as trace.id, the attribute New Relic uses to show logs on a trace. A key like traceId would be saved but not linked.

Added to every browser log

  • session, the browser session ID
  • ptid, the page view's trace ID
  • pageUrl and your custom attributes, like demoCode

You add per request

  • trace.id from the traceparent your request carried (this page captures it)
  • or from the response: the demo backend returns x-trace-id, exposed through CORS
// After a request: log with the same trace ID the request carried
const traceId = traceparent.split('-')[1]  // version-TRACEID-parentId-flags
newrelic.log('GET /api/products 200', {
  level: 'info',
  customAttributes: { 'trace.id': traceId, requestUrl: '/api/products' }
})

On the server, the Node.js agent's newrelic.recordLogEvent() adds trace.id and span.id for you, so checkout writes three backend logs (inventory, payment, checkout) onto your trace. Successful requests log at INFO, so set your app's manual log verbosity to INFO or lower in Application settings.

2 · A user journey

Checkout flow

One click, three requests in a row: cart, checkout, order. With the backend, checkout also calls internal inventory and payment services, which appear as child spans in the same trace.

3 · When things go wrong

Slow and failing calls

Traces show you where the time went and which hop failed. Slow and server-error calls need the backend.

4 · Cross-origin

Requests that are not traced

Browsers block custom headers on cross-origin requests unless the other server allows them. So the agent only adds trace headers to origins you list under CORS in Application settings.

3 · Didn't see it?

      

        
No backend spans?In browser-only mode that is expected. Static files have no APM agent. Connect the backend in backend/README.md to see the full path.

        
No INFO logs?Successful requests log at INFO. If your app keeps only WARN and above, raise the manual log verbosity under Browser > Application settings.

        
Backend not joining?The inspector's status for each request says which piece is missing. backend/README.md lists the three settings that have to line up for a backend on another domain.

A request to a third-party API went out with no trace headers. Why?

          

          
Browsers block custom headers on other cross-origin requests, so you list the origins that accept them in Application settings.

        

        

          
Do logs from newrelic.log() appear on a trace automatically?

          

          
The agent doesn't add a trace ID to browser logs. trace.id is the attribute New Relic uses to link a log to a trace.
