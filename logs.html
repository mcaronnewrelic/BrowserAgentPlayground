Everyone shares one New Relic account, so we tag your logs. Your name and session code are attached to every log as demoUser and demoCode, your name also becomes your end-user ID via newrelic.setUserId(), and the code is added to the start of each message.

  • Application settingsAutomatically collect console logs, for console calls.

Method 1 · Automatic

Console auto-logging

The agent watches the browser console. No code changes needed, just turn on Automatically collect console logs in Application settings.

Method 3 · Wrap your logger

            
newrelic.wrapLogger()

            
This page has its own little logger, appLogger, which writes to the box below and not to the console. Each method was wrapped once at page load, so every call also becomes a New Relic log event. The first argument becomes the message.

            
// Run once at page load
newrelic.wrapLogger(appLogger, 'info',  { level: 'info',  customAttributes: { loggerName: 'appLogger' } })
newrelic.wrapLogger(appLogger, 'warn',  { level: 'warn',  customAttributes: { loggerName: 'appLogger' } })
newrelic.wrapLogger(appLogger, 'error', { level: 'error', customAttributes: { loggerName: 'appLogger' } })

A console.debug() call shows up in this page's feed but never in New Relic. Why?

          

          
This app keeps WARN and above, so DEBUG logs are dropped. The feed marks them as filtered for that reason.

        

        

          
Collect logs manually is on, but your console.warn() calls still don't arrive. What's missing?

          

          
Console calls have their own switch. Manual collection covers only newrelic.log() and wrapLogger().
