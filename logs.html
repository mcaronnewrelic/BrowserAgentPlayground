Make some logs

There are three ways to get browser logs into New Relic, plus a few realistic scenarios. Each button shows the log level it creates and whether that level is kept at WARN.

Method 1 · Automatic

Console auto-logging

The agent watches the browser console. No code changes needed, just turn on Automatically collect console logs in Application settings.

Method 2 · API

newrelic.log()

Send one log event with a level you choose and your own attributes.


            

              
              
            

          


          
          

            
Method 3 · Wrap your logger

            
newrelic.wrapLogger()

            
This page has its own little logger, appLogger, which writes to the box below and not to the console. Each method was wrapped once at page load, so every call also becomes a New Relic log event. The first argument becomes the message.

            
// Run once at page load
newrelic.wrapLogger(appLogger, 'info',  { level: 'info',  customAttributes: { loggerName: 'appLogger' } })
newrelic.wrapLogger(appLogger, 'warn',  { level: 'warn',  customAttributes: { loggerName: 'appLogger' } })
newrelic.wrapLogger(appLogger, 'error', { level: 'error', customAttributes: { loggerName: 'appLogger' } })
